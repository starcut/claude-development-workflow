# /ssc-bugfix

既存の不具合を修正する。

## 進め方
1. 不具合の内容と既存仕様を確認する。
2. 不具合の原因特定に必要な範囲を調査する。
3. 調査結果から、原因と修正対象となるファイルを整理し、ユーザーに確認する。
4. 修正方法を判断できるか確認する。
5. 修正方針や仕様上の確認が必要な場合は、修正前に方針を整理し、ユーザーに確認する。
6. ユーザーの確認後、修正する。

## ルール
- 不具合の原因特定に必要な範囲を超えて調査しない。
- 必要な場合はユーザーに確認する。
- 依頼されていない変更を行わない。
- 不要なリファクタリングを行わない。
- 既存の設計・実装を尊重し、独自の設計変更を行わない。
- 仕様や修正方法について判断できない場合は、推測で決定しない。
