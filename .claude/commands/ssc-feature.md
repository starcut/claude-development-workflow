# /ssc-feature

新規機能を実装する。

## 進め方

1. 依頼内容と既存仕様を確認する。
2. 実装する機能と変更対象となるファイルを、ユーザーに確認する。
3. 実装に必要な範囲を調査する。
4. 設計上の判断や仕様上の確認が必要な場合は、実装前に方針を整理し、ユーザーに確認する。
5. ユーザーの確認後、実装する。

## ルール

- 依頼された機能に必要な範囲を超えて調査しない。
- 必要な場合はユーザーに確認する。
- 依頼されていない変更を行わない。
- 不要なリファクタリングを行わない。
- 既存の設計・実装を尊重し、独自の設計変更を行わない。
- 仕様や設計について判断できない場合は、推測で決定しない。
